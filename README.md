# 🏢 东莞市既有住宅增设电梯分摊计算器

这是一个基于 HTML、CSS 和 JavaScript 开发的网页应用，旨在帮助东莞市老旧小区业主根据《东莞市既有住宅增设电梯管理办法（修订）》快速计算电梯增设费用的分摊方案。

在线演示地址：[你的GitHub用户名].github.io/elevator-calculator

## 📊 功能特性

- **双预设方案**：内置两种官方推荐或常见的分摊方案。
- **自定义计算**：支持用户手动调整分摊系数、总造价和补贴金额。
- **明细展示**：详细列出每层楼的分摊金额、补贴抵扣及最终实付金额。
- **响应式设计**：适配桌面端和移动端浏览。

## 🛠️ 核心逻辑

该计算器基于**分摊系数**进行计算，核心公式如下：

1.  **总系数计算**：累加所有参与分摊楼层的系数。
2.  **楼层分摊金额**：`(总造价 / 总系数) * 该楼层系数`
3.  **特殊分配逻辑（关键点）**：
    代码中包含一段特定的逻辑：**9层的分摊金额和补贴金额会按系数分配到2-8层**。这意味着在最终实付金额中，2-8层的业主实际上共同承担了9层的份额（具体表现为：`最终实付 = 原本应付 + 9层分摊分配额 - 9层补贴分配额`）。

## 📝 方案说明

| :--- | :--- | :--- | :--- |
| **方案一** | 基础方案 | 0.5 | 从 1.0 递增至 1.6 |
| **方案二** | 2层不出资方案 | 0.0 | 从 1.0 递增至 1.6 |

## 🚀 快速开始

### 1. 本地运行
由于这是一个纯前端静态页面，无需服务器环境，你可以直接下载并双击 `index.html` 文件在浏览器中打开。

### 2. 在线修改
如果你希望修改分摊系数或样式：
1.  克隆本仓库。
2.  修改 `DOCTYPE.txt`（建议重命名为 `index.html`）文件。
3.  在 `<script>` 标签内的 `schemeCoefficients` 对象中调整系数数组。
4.  重新部署。

### 代码片段示例 (系数配置)
```javascript
const schemeCoefficients = {
  1: [0.5, 1, 1.1, 1.2, 1.3, 1.4, 1.5, 1.6], // 方案一
  2: [0, 1, 1.1, 1.2, 1.3, 1.4, 1.5, 1.6]     // 方案二
};
